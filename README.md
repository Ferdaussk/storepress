# StorePress Todo Manager

A modern, full-stack Todo management solution built as a WordPress plugin plan using Gutenberg (React) for the frontend and a dynamic admin dashboard for centralized management.

This project demonstrates scalable plugin architecture, WordPress-native development practices, and real-time data synchronization between frontend and backend.

---

## Features

### Frontend (Gutenberg Block)
- Add new todos instantly
- Mark todos as complete/incomplete
- Delete todos
- No page reload
- Persistent data after refresh

### Admin Dashboard
- View all todos in one place
- Add, edit, and delete todos
- Inline editing experience
- No page reload

### Core Capabilities
- Shared data source between frontend and admin
- Real-time synchronization via REST API
- Clean and modular architecture
- WordPress native implementation
